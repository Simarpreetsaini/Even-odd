# Even or Odd Checker

## Objective

This program checks whether a number is even or odd using if-else statements.

## How it Works

- I created four number variables.
- I used if-else to check each number.
- If the number is divisible by 2, it is even.
- Otherwise, it is odd.
- The result is displayed in the console and on the webpage.

## Output

* The number 5 is odd.
* The number 10 is even.
* The number 7 is odd.
* The number 12 is even.
